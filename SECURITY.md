# Security Policy

## Supported version
Security fixes are expected only for the latest state of the default branch.

## Reporting a vulnerability
Please do not open a normal GitHub issue for sensitive security reports.

Preferred path:
1. Use GitHub private vulnerability reporting for this repository if it is enabled.
2. If it is not enabled yet, contact the maintainer through a private channel already used for this repository.

When reporting, include:
- a short description of the issue
- reproduction steps or proof of concept
- impact
- any suggested mitigation

## Out of scope
This project is a client-side countdown app and does not manage wallets, keys, or on-chain funds. Still, please avoid posting private tokens, local environment details, or other sensitive data in public reports.
